# Security Policy

## Supported Versions

Currently, security updates are only provided for the latest release of Model Hub.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Model Hub, please do not open a public issue. Instead, report it privately to ensure the safety of our users.

Please report security issues by emailing:
**hello@consciousengines.com**

Please include as much detail as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge your report within 48 hours and work with you to resolve the issue as quickly as possible.
